# Web Technology Lab Repository

## Overview
This repository contains Web Technology laboratory exercises and mini-projects developed as part of a Web Technology course. The projects demonstrate front-end development, JavaScript programming, AJAX, XML/JSON processing, Node.js, Express.js, React.js, and MongoDB concepts.

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
- AJAX
- XML
- JSON
- Node.js
- Express.js
- React.js
- MongoDB
- Git & GitHub

## Getting Started

### Clone the Repository

```bash
git clone <repository-url>
cd Web-Technology-main
```

### HTML Projects
Open the `index.html` file directly in your browser or use the **Live Server** extension in VS Code.

### Node.js Projects

```bash
npm install
npm start
```

### React Projects

```bash
npm install
npm start
```
